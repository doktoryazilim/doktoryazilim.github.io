# 5S Tech

Güvenlik teknolojileri mağazası (PWA). Telefona ve bilgisayara uygulama gibi yüklenebilir.

## Dosyalar
- `index.html` — site (tasarım ve kod)
- `manifest.json` — uygulama bilgileri
- `service-worker.js` — çevrimdışı önbellek
- `icon-192.png`, `icon-512.png` — uygulama ikonları

## Yayınlama
GitHub: Settings > Pages > Deploy from a branch > main > / (root)
Firebase: Authentication > Settings > Authorized domains alanına `KULLANICIADIN.github.io` ekleyin.
